logs reported `PW_WINE64 cpu=native prefix_cpu=0`. Treat that comparison as a
native run; the selected CPU mode did not match the runtime's reported mode.
The successful music-disabled run also logged native mode. Do not claim a
translator-versus-native result from those runs.
